# Лабораторная работа №3. Крупный ООП-проект «Компьютер»

Объектная модель компьютера на Python: процессор, ядра, кэш, регистры, АЛУ, материнская плата,
оперативная и виртуальная память, накопители и файловая система, видеокарта и вывод изображения,
шины и контроллеры ввода-вывода, питание и охлаждение, прошивка BIOS/UEFI и диагностика.

## Итоговая статистика

| Показатель | Требование | В проекте |
|---|---|---|
| Классы предметной области | ≥ 50 | 52 |
| Поля (суммарно) | ≥ 150 | 196 |
| Содержательные поведения (публичные методы) | ≥ 100 | 168 |
| Ассоциации между классами | ≥ 30 | 74 |
| Собственные исключения | ≥ 12 | 15 |
